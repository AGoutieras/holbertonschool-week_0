# Emacs

* ## **[0. Create your answer directory](0-emacs)**

Navigate to ```/root``` and create a directory named ```emacs```

<details>
<summary>Show answer</summary>

```bash
cd /root
mkdir emacs
```
</details>

---

* ## **[1. Opening](1-opening)**

What is the command to open a file from within Emacs?

Write the answer into the file ```/root/emacs/opening```.

You can validate if the format of your answer is correct by displaying the file information:

<details>
<summary>Show answer</summary>

```bash
C-x C-f filename
```
</details>
