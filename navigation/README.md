# Shell, navigation

* ## **[0. Create me!](0-create_me)**

Access your sandbox and:

* Change your working directory to ```/root```
* Then, create an empty file ```so_cool```

<details>
<summary>Show answer</summary>

```bash
cd /root
touch so_cool
```
</details>
