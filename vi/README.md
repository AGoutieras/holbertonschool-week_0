# vi

* ## **[0. Create your answer directory](0-vi)**

Navigate to ```/root``` and create a directory named ```vi```

<details>
<summary>Show answer</summary>

```bash
cd /root
mkdir vi
```
</details>

---

* ## **[1. Inserting](1-inserting)**

What is the command to insert text before the cursor?

Write the answer into the file ```/root/vi/inserting```.

You can validate if the format of your answer is correct by displaying the file information:

<details>
<summary>Show answer</summary>

```bash
i
```
</details>

* ## **[2. Cutting](2-cutting)**

What is the command to delete and cut the current line?

Write the answer into the file ```/root/vi/cutting```.

<details>
<summary>Show answer</summary>

```bash
yy
```
</details>

* ## **[3. Pasting](3-pasting)**

What is the command to paste the lines in the buffer into the text after the current line?

Write the answer into the file ```/root/vi/pasting```.

<details>
<summary>Show answer</summary>

```bash
p
```
</details>

* ## **[4. Undoing](4-undoing)**

What is the command to undo what you just did?

Write the answer into the file ```/root/vi/undoing```.

<details>
<summary>Show answer</summary>

```bash
u
```
</details>

* ## **[5. Exiting](5-exiting)**

What is the command to quit vi even though latest changes have not been saved for this vi call?

Write the answer into the file ```/root/vi/exiting```.

<details>
<summary>Show answer</summary>

```bash
:q!
```
</details>
